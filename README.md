# StudyOS MAX

A mobile-friendly, Quizlet MAX-inspired study workspace built with plain HTML, CSS, and JavaScript.

## Features
- Flashcards with shuffle and flip
- Learn mode with multiple-choice practice and mastery tracking
- Generated practice tests
- Timed term/definition matching
- Offline study coach with rule-based explanations and study plans
- Paste notes to draft flashcards
- Study sets, progress, streaks, and session history
- Browser autosave using localStorage
- JSON backup export

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site.

## Important notes
- Study sets and progress are stored in the current browser on the current device. They are not synced between devices and are not attached to a user account.
- The study coach and note-to-card generator run locally in the browser. They are not connected to a hosted AI model and do not browse the web.
- Export a JSON backup from the Study Coach or Progress page to keep a copy of your data.
